# Portfolio-Web

Portfolio web de Agustina Rodriguez — QA Tester.

Tecnologías: React + Vite. Mobile-first. Tipografía: Montserrat.

Cómo ejecutar localmente:
1. Instalar dependencias:
   - npm install
2. Ejecutar en desarrollo:
   - npm run dev
3. Construir:
   - npm run build
4. Previsualizar build:
   - npm run preview

Deploy:
- Recomendado: Vercel. Importar el repo desde GitHub y usar:
  - Build command: npm run build
  - Output directory: dist
